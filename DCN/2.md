# Beijing Digital China Cloud Technology Co., Ltd. Vendor firewall has a command execution vulnerability

## 1. Vulnerability Overview

Product Company Website:

https://www.dcnimcloud.com/

Product Company Introduction:

Beijing Digital China Cloud Technology Co., Ltd. (DCN) is a professional company under the Digital China Group that owns its own network and cloud brands and intellectual property rights. It is one of the earliest network and cloud equipment and solution providers in the world to engage in IPv6, and one of the earliest network and cloud equipment manufacturers in China to pass the IPv6 Ready Gold Certification and OpenFlow v1.3 Certification.

Vulnerability hazards:

The Vendor firewall of Beijing Digital China Cloud Technology Co., Ltd. has a command execution vulnerability, which can be exploited to obtain device administrator privileges.

Vulnerability affects products: vendor

Vulnerability affected versions: version 7.2.6.120

Distribute CVE ID: CVE-2024-51114

![image](https://github.com/user-attachments/assets/c162516d-f6b3-4de0-b8c8-6ea94dc1edd4)



## 2. Vulnerability Code Audit

Open the firewall source code/function/dpi/web_auth/customizable.php file and you will see that line 94 uses the getVar function to get the img parameter value from the front end, and line 100 passes the img variable to the exec function through splicing to execute the system command.

![image](https://github.com/user-attachments/assets/4003390d-2ca4-48cd-a759-4f9fe50e5b49)
