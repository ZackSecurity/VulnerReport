# Beijing Digital China Yunke Information Technology Co. Ltd DCN firewall has a command execution vulnerability

## 1. Vulnerability Overview

Product Company Website:

https://www.dcnimcloud.com/

Product Company Introduction:

Beijing Digital China Cloud Technology Co., Ltd. (DCN) is a professional company under the Digital China Group that owns its own network and cloud brands and intellectual property rights. It is one of the earliest network and cloud equipment and solution providers in the world to engage in IPv6, and one of the earliest network and cloud equipment manufacturers in China to pass the IPv6 Ready Gold Certification and OpenFlow v1.3 Certification.

Vulnerability hazards:

The DCN firewall of Beijing Digital China Cloud Technology Co., Ltd. has a command execution vulnerability, which can be exploited to obtain device administrator privileges.

Vulnerability affects products: DCME-320

Vulnerability affected versions: version 7.4.12.60

Distribute CVE ID: CVE-2024-42905


## 2. Vulnerability Code Audit

Open the firewall source code/function/system/tool/ping.php file and see that the getVar function gets the host, proto, and count parameter values from the front end. In line 25, these three parameters are concatenated into the cmd variable, and finally the cmd variable is stored in the data array:

![image](https://github.com/user-attachments/assets/83b79616-df0e-4224-aef5-08da98cca469)


Tracing the data array, we can see that in line 109, it is determined whether the cmd element of the data array exists. If it exists, in line 119, the cmd element of the data array is passed to the system function to execute the system command.

![image](https://github.com/user-attachments/assets/23ef09ed-561d-45f9-bb52-f5d8858047f8)
